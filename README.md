# 📱 Android Studio Lite for Mobile (OxDroid Workspace)

## 💡 The Vision: Why Does This Exist?
Every great developer's journey doesn't start with a high-end MacBook or a 16GB RAM PC. Millions of passionate students, dreamers, and self-taught coders around the world only have access to a simple smartphone. 

While the official Android Studio is an incredible tool, it is heavy and requires powerful hardware. This leaves mobile-only users behind. **We want to change that.** 

This project is built on a simple belief: **If you have an Android phone and an idea, you should be able to build an app.** No PC required.

## 🚀 What is this?
This is a 100% Open-Source Native Mobile IDE built *on* Android, *for* Android. It aims to replicate the core experience of a desktop IDE—complete with a workspace, file explorer, code editor, and a real-time build engine—right on your smartphone.

## ✨ Features (What we have built so far)
- **Premium UI/UX:** A beautiful, dark-themed workspace inspired by professional desktop IDEs.
- **Project Editor:** Sidebar project explorer, dynamic file switcher, and a dedicated text area for coding.
- **Native Build Pipeline:** Integrated shell scripts that utilize AAPT2, ECJ, and D8 to compile and package APKs directly on the device.
